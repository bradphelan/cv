# CV Translation Instructions

When asked to translate the CV, or whenever `README.md` is modified, read `README.md`,
translate it into German following the rules below, and write the result to `README.de.md`.

## Rules

- Translate all prose, headings, and labels into natural professional German
- Keep all proper nouns unchanged: company names, product names, tool names,
  programming languages, technology names (e.g. C++, WPF, DO-178B, Fusion 360)
- Keep all dates and date ranges unchanged
- Keep all URLs unchanged
- Job titles should use standard German equivalents where they exist:
  - "Principal Software Engineer" → "Principal Software Engineer" (keep, no standard German equivalent)
  - "Lead Software Engineer" → "Leitender Software-Ingenieur"
  - "Senior Software Engineer" → "Senior Software-Ingenieur"
  - "Software Engineer" → "Software-Ingenieur"
  - "Project Engineer" → "Projektingenieur"
  - "Graduate / Project Engineer" → "Absolvent / Projektingenieur"
- Section headings should be translated:
  - "Summary" → "Zusammenfassung"
  - "Experience" → "Berufserfahrung"
  - "Education" → "Ausbildung"
  - "Skills" → "Kenntnisse"
  - "Languages" → "Sprachen"
  - "Interests" → "Interessen"
- Proficiency levels:
  - "Native" → "Muttersprache"
  - "Limited working proficiency" → "Grundlegende Berufskenntnisse"
- Tone: formal, concise, appropriate for a German engineering CV
- Do not add or remove any content — this is a direct translation only
- Output only the translated markdown, no preamble or commentary
